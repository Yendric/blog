Lyri is a native Windows live lyrics app written using the new [Windows Reactor](https://crates.io/crates/windows-reactor) in Rust. It shows synced lyrics for the music you're currently playing, following along line by line. Lyri can also host a small server from the app, allowing other Lyri clients and web clients to view the live lyrics as well.
