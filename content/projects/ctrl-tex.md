ctrl.tex is a small background utility written in Rust that converts selected LaTeX code into Unicode characters in-place. Select `\forall x \in \mathbb{R}` anywhere, press the shortcut, and it becomes `∀x ∈ ℝ`. Useful when discussing maths in apps like Discord, for example.

The source code can be found on my Github: <https://github.com/Yendric/ctrl.tex>
